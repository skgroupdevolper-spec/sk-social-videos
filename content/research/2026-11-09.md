## Video 1 — Shopify store speed (pillar: Shopify / Performance; type: educational)
- **Primary keyword:** why is my shopify store slow
- **Secondary:** shopify speed optimization · speed up shopify store · shopify store slow on mobile · shopify apps slowing down store · shopify theme performance
- **Intent:** problem-solving / informational with commercial follow-up (owner wants the fix or someone to do it).
- **Audience problem:** store feels slow on phones; speed score stays low even after compressing images (a recurring Shopify Community thread title).
- **Angle:** four usual causes — oversized images, too many apps, code left behind by uninstalled apps, render-blocking scripts — and what a theme-level fix looks like (resize/lazy-load below-the-fold images but not the hero, defer scripts, remove orphaned snippets, then re-measure on mobile).
- **Why now:** run-up to the holiday season, when stores get the most mobile traffic; many ranking guides are dated 2026, so the question is actively searched.
- **Sources:**
  - https://www.fudge.ai/guides/how-to-speed-up-a-shopify-theme (causes + fixes, hero image should not be lazy-loaded, measure LCP/INP/CLS)
  - https://community.shopify.com/t/shopify-store-has-a-slow-mobile-speed-score-even-after-optimizing-images/675165
  - https://support.nextsky.co/general/troubleshooting/shopify-store-slow/
  - https://scandiweb.com/blog/shopify-performance-optimization/
  - https://shopifygenius.blogspot.com/2026/01/why-shopify-store-is-slow.html
- **Not claimed:** no load-time numbers, conversion-rate percentages or "X% faster" promises.

## Video 2 — Mobile app vs web app (pillar: Mobile / Flutter + custom web apps; type: capability)
- **Primary keyword:** mobile app vs web app for business
- **Secondary:** do I need an app for my business · progressive web app vs native app · flutter app development · web app or mobile app first · cross-platform app development
- **Intent:** decision / commercial investigation.
- **Audience problem:** founders and small businesses assume they need an app-store app, when a web app may cover the job — or they need store presence and push notifications and don't know a cross-platform route exists.
- **Angle:** start with a web app when people find you through search, need it on any device and you want one update for everyone; choose a mobile app for app-store presence, reliable push notifications, fuller offline use and deeper device features; with Flutter one codebase serves Android and iOS and shares the same backend/API as the web app.
- **Why now:** 2026 decision guides comparing web app vs PWA vs native/cross-platform are ranking widely, so it is a live question.
- **Sources:**
  - https://www.mobiloud.com/blog/flutter-vs-pwa (store listing only for native apps; PWA push needs home-screen install first; native offers fuller offline and device access)
  - https://www.cubix.co/blog/web-app-vs-website-vs-pwa/
  - https://binmile.com/blog/flutter-vs-react-native-vs-pwa
  - https://www.zartek.in/flutter-vs-pwa-which-is-better/
- **Not claimed:** cost figures in the sources were deliberately left out (no prices in our content); no claims about performance numbers.
